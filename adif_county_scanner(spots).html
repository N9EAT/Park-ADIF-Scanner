Band and mode awards come from the award file name (e.g. "… 6 Meters Award"), which locks the Band/Mode filters below to that award's band or mode.
The award is read from the file name: USA-CA, USA-PA (All Prefix), USA-PA - K/W/N/A, Call Combo - 1x2 (also 2x1, 1x3, 2x2, 2x3), or a band/mode award like 1.25 Meters Award. Unrecognized names are rejected with an error. File contents use the CQ record-book format ("State:" then county list).

Mode groups — SSB/Phone: SSB · USB · LSB · AM · FM · digital voice  ·  CW: CW  ·  Digital: everything else (FT8, FT4, RTTY, PSK…). County names are matched after stripping punctuation and spacing, so "St. Clair" = "St Clair" and Alaska's "Third J.D. SC" = "Third J. D. S C". Alaska borough/census-area names in logs are mapped to the four USA-CA judicial districts, and "Saint"/"Sainte" match "St."/"Ste.". Satellite QSOs (PROP_MODE=SAT or SAT_NAME) count only toward USA-CA Satellite. Reference fields per the ADIF specification. Everything runs in your browser — no data leaves this page.
